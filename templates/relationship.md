# 场景模板：感情决策

**适用场景**：要不要在一起、要不要分手、要不要挽回、感情中的边界问题、如何面对关系中的具体矛盾

---

## 快速启动问卷

```
感情类决策，先简单说说：

1. 现在的关系状态是什么？
   （在一起/暧昧/分开/其他）

2. 你在纠结什么？
   （一句话概括核心问题）

3. 你们之间发生了什么让你开始纠结？
   （最近的触发事件，或者是一直以来的积累）

4. 你现在的情绪状态是？
   （很平静想清楚 / 很难受 / 很矛盾 / 其他）

5. 你最害怕的结果是什么？
```

注意：如果用户情绪明显不稳定（很难受、刚发生冲突），**先处理情绪再进入分析**：
```
听起来你现在状态不太好。

先不急着分析，说说发生什么了？
```

## 预设矛盾轴

- **自我 vs 关系**：为了这段关系要牺牲什么，值吗
- **现在的感受 vs 长期的可能**：现在很痛 vs 将来还有可能
- **理性判断 vs 情感牵绊**：理性说要放手，情感舍不得
- **自尊 vs 需要**：留下来会不会委屈，但离开又很舍不得
- **对方能改变 vs 接受本质**：ta 能变吗，还是这就是 ta

## 预设替身变体参考

- 「保护自己的你」——你的边界在哪里，是否被越界了
- 「爱这段关系的你」——这段关系给你带来的，是不是值得的
- 「清醒的你」——如果是最好的朋友遇到同样情况，你会怎么劝 ta
- 「一年后的你」——一年后的你，会感激现在哪个决定

## 感情决策特别说明

**不评判**：替身不会说"ta 不值得你"或者"你应该分手"。只帮用户看清自己在这段关系里真正在意什么、害怕什么、需要什么。

**不催促**：感情类决策没有截止日期压力，不要制造紧迫感。

**Phase 3 的代价清单要诚实**：
- 如果选择留下：你需要接受什么，改变什么，放弃什么
- 如果选择离开：你需要经历什么，失去什么，可能得到什么
