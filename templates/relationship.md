# 场景模板：感情决策

**适用场景**：要不要在一起、要不要分手、要不要挽回、感情中的边界问题、如何面对关系中的具体矛盾

---

## 快速启动问卷

```
感情类决策，先简单说说：

1. 现在的关系状态是什么？
   （在一起/暧昧/分开/其他）

2. 你在纠结什么？
   （一句话概括核心问题）

3. 你们之间发生了什么让你开始纠结？
   （最近的触发事件，或者是一直以来的积累）

4. 你现在的情绪状态是？
   （很平静想清楚 / 很难受 / 很矛盾 / 其他）

5. 你最害怕的结果是什么？
```

**注意**：如果用户情绪明显不稳定（很难受、刚发生冲突），**先处理情绪再进入分析**：
```
听起来你现在状态不太好。

先不急着分析，说说发生什么了？
```

## 预设矛盾轴（结构化）

```yaml
tension_axes:
  primary: "self_vs_relationship"    # 自我 vs 关系
  secondary: "rational_vs_intuitive" # 理性判断 vs 情感牵绊
  optional: "short_vs_long"          # 现在的感受 vs 长期的可能
```

常见场景下的主轴：
- 要不要分手 → `self_vs_relationship`（主）+ `rational_vs_intuitive`（次）
- 要不要挽回 → `short_vs_long`（主）+ `self_vs_relationship`（次）
- 感情边界问题 → `self_vs_relationship`（主）+ `control_vs_belonging`（次）

## 典型自问清单

Phase 3 综合时可作为"做决定前先想清楚这几件事"的候选来源：

1. **触发事件 vs 长期模式**：这次纠结是因为一件具体的事，还是积累已久的模式？如果是后者，这件事解决了有用吗？
2. **害怕失去 vs 真的想要**：你想留住的，是这个人，还是"有人陪"的感觉？
3. **对方能改变吗**：你期待对方改变的那件事，ta 有没有表示过愿意改？还是你一直在等一个没有承诺的改变？
4. **代价的方向**：留下来要付出什么，离开要付出什么——你现在能承受哪个代价？
5. **你的底线**：有没有一件事，如果发生了，是你无论如何都接受不了的？它发生了吗？

---

## Phase 3 特别说明

- **不评判**：替身不会说"ta 不值得你"或者"你应该分手"。只帮用户看清自己在这段关系里真正在意什么、害怕什么、需要什么。
- **不催促**：感情类决策没有截止日期压力，不要制造紧迫感。
- **代价清单要诚实**：
  - 如果选择留下：你需要接受什么，改变什么，放弃什么
  - 如果选择离开：你需要经历什么，失去什么，可能得到什么
