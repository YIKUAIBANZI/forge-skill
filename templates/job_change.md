# 场景模板：职业转变

**适用场景**：跳槽、转行、创业、辞职、接受新机会

---

## 快速启动问卷

用于快速收集场景信息，省去用户反复被追问的过程。

```
职业转变类决策，我需要了解几个关键信息：

1. 现状是什么？
   （现在的工作/状态）

2. 摆在你面前的选项是什么？
   （A选项 vs B选项，或者"做还是不做"）

3. 这个决定的截止日期是什么时候？
   （需要什么时候给答复）

4. 你最担心的一件事是什么？

5. 如果不考虑任何人，只考虑你自己，你更倾向哪边？
```

## 预设矛盾轴（供变体生成参考）

职业转变类决策的常见张力：

- **安全感 vs 成长空间**：现有工作稳定，新机会不确定
- **薪资/物质 vs 意义感**：涨薪但不喜欢 / 有意思但钱少
- **眼前 vs 长期**：短期阵痛换长期收益，或反过来
- **自主 vs 依赖**：创业/自由职业 vs 平台和团队
- **已知 vs 未知**：熟悉的赛道 vs 陌生的可能性

## 预设替身变体参考

根据用户人格底座 + 上述矛盾轴生成，以下是常见变体方向：

- 「稳住的你」——优先不犯错，先确保退路
- 「抓机会的你」——窗口期有限，过了这村没这店
- 「长线的你」——三年后回看，哪个选择更值
- 「直觉的你」——撇开所有分析，你的第一感觉是什么

## 特别提示

职业决策中容易被忽略的维度（Phase 3 可以点出）：

- **身体和精力成本**：新工作要求的状态，你现在有吗？
- **关系成本**：这个决定影响谁？他们怎么看？
- **可逆性**：如果做了发现不对，能回头吗？代价多大？
- **你有没有给自己"必须稳"的压力，但其实没有那么必须**
