# 场景模板：财务/投资决策

**适用场景**：大额消费、投资理财、借贷、创业注资、买房、职业和金钱的取舍

---

## 快速启动问卷

```
财务决策，先说几个关键数字：

1. 这个决定涉及多少钱？
   （大概量级，不需要精确）

2. 这笔钱对你来说是什么量级？
   （随便花 / 有点肉疼 / 需要很久才能存到 / 是我的大部分积蓄）

3. 最坏情况是什么？
   （如果这笔钱完全没了，你的生活会怎样？）

4. 这个决定有时间窗口吗？
   （现在不做就没了 / 随时可以 / 不确定）

5. 你最担心的是什么？
   （钱没了？后悔？还是其他？）
```

## 预设矛盾轴

- **安全 vs 收益**：稳的选择收益低，高收益伴随高风险
- **短期流动性 vs 长期增值**：钱放在那里不动 vs 可能的收益
- **机会成本 vs 确定损失**：不做这个机会，做那个机会
- **理性预期 vs 情绪波动**：数据说可以，但心里不踏实（或反过来）
- **自己判断 vs 依赖他人**：自己想清楚了 vs 专家/朋友说的

## 预设替身变体参考

- 「保守的你」——最坏情况能不能承受，先从这里想
- 「长线的你」——五年后这笔钱的决策对你意味着什么
- 「机会的你」——不做这个决定的机会成本是多少
- 「情绪归零的你」——把 FOMO（错过恐惧）或者焦虑去掉，你还会这么想吗

## 财务决策特别说明

**量化很重要**：在 Phase 1 里，鼓励每个变体给出具体数字或场景，而不是"可能会有损失"这种模糊表述。

**Phase 3 必须有的内容**：
- 最坏情况的具体影响（不是"很惨"，而是"这意味着你需要..."）
- 可逆性评估（能止损吗？止损成本多少？）
- 这个决定依赖的关键假设是什么（如果假设不成立，结论怎么变）
