# 场景模板：财务/投资决策

**适用场景**：大额消费、投资理财、借贷、创业注资、买房、职业和金钱的取舍

---

## 快速启动问卷

```
财务决策，先说几个关键数字：

1. 这个决定涉及多少钱？
   （大概量级，不需要精确）

2. 这笔钱对你来说是什么量级？
   （随便花 / 有点肉疼 / 需要很久才能存到 / 是我的大部分积蓄）

3. 最坏情况是什么？
   （如果这笔钱完全没了，你的生活会怎样？）

4. 这个决定有时间窗口吗？
   （现在不做就没了 / 随时可以 / 不确定）

5. 你最担心的是什么？
   （钱没了？后悔？还是其他？）
```

## 预设矛盾轴（结构化）

```yaml
tension_axes:
  primary: "safety_vs_growth"      # 安全 vs 收益
  secondary: "short_vs_long"       # 短期流动性 vs 长期增值
  optional: "rational_vs_intuitive" # 数据说可以，但心里不踏实
```

常见场景下的主轴：
- 投资/理财 → `safety_vs_growth`（主）+ `rational_vs_intuitive`（次）
- 买房 → `short_vs_long`（主）+ `self_vs_relationship`（次，家庭因素）
- 创业注资 → `control_vs_belonging`（主）+ `safety_vs_growth`（次）

## 典型自问清单

1. **最坏情况**：这笔钱完全没了，对你的生活具体意味着什么？能承受吗？
2. **关键假设**：你的判断依赖哪个核心假设？如果这个假设不成立，结论怎么变？
3. **可逆性**：能止损吗？止损的成本多大？还是一旦做了就没有回头路？
4. **时间窗口的真实性**：这个机会真的有时限，还是对方/市场在制造紧迫感？
5. **信息来源**：你的判断主要来自自己研究，还是别人说的？别人有没有利益关系？
6. **情绪因素**：你有没有因为 FOMO（怕错过）、或者已经投入的沉没成本，影响了判断？

## Phase 3 特别说明

**量化很重要**：鼓励每个变体给出具体数字或场景，而不是"可能会有损失"这种模糊表述。

代价清单里必须有的：
- **最坏情况的具体影响**（不是"很惨"，而是"这意味着你需要..."）
- **可逆性评估**（能止损吗？止损成本多少？）
- **关键假设清单**（这个决定成立的前提是什么）
