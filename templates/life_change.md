# 场景模板：重大生活变化

**适用场景**：搬家/移居、结婚、要不要孩子、重大健康决策、离开一段长期关系或环境

---

## 快速启动问卷

```
重大生活变化，这类决定通常牵涉很多层面，先整体说说：

1. 你在考虑什么样的变化？

2. 是什么让你开始认真考虑这件事？
   （一直有这个想法 / 最近发生了什么 / 外部压力）

3. 如果做了这个改变，哪些东西会跟着变？
   （工作/关系/生活方式/经济/其他）

4. 你觉得"不变"的代价是什么？

5. 你有没有跟别人聊过这件事？他们怎么说？
```

## 预设矛盾轴（结构化）

```yaml
tension_axes:
  primary: "known_vs_unknown"       # 已知的不适 vs 陌生的可能
  secondary: "self_vs_relationship"  # 个人意愿 vs 牵涉他人
  optional: "ideal_vs_reality"       # "应该" vs "想要"
```

常见场景下的主轴：
- 移居/搬家 → `known_vs_unknown`（主）+ `self_vs_relationship`（次）
- 结婚/要孩子 → `self_vs_relationship`（主）+ `ideal_vs_reality`（次）
- 离开长期环境 → `safety_vs_growth`（主）+ `known_vs_unknown`（次）

## 典型自问清单

1. **真实的驱动力**：是你真的想改变，还是在逃避现状里的某件具体的事？如果只解决那件事，你还会想改变吗？
2. **紧迫感的来源**：这个改变现在必须做，还是焦虑制造了紧迫感？再等一年结果会差很多吗？
3. **最小实验**：这个改变是"一步到位"，还是可以先做一个小实验感受一下？
4. **不变的代价**：如果五年后还是现状，你能和解吗？还是会后悔没动？
5. **牵涉他人**：这个决定影响最大的人，知道你在考虑这件事吗？他们的态度是你需要纳入考量的吗？
6. **"应该"的来源**：你感到的压力或期待，是自己真正想要的，还是来自外部（家人、社会时钟、周围人）？

---

## Phase 3 特别说明

这类决定通常**不需要马上做**，也很少是真正的"现在不做就没了"。Phase 3 要帮用户分辨：
- 是真的现在必须决定，还是焦虑制造出来的紧迫感？
- 这个变化是"一步到位"，还是可以先做一个小实验？

**不要低估"不变"的代价**：很多人用"这很麻烦/这很冒险"逃避改变，但不变同样有代价。替身要两边都诚实。
