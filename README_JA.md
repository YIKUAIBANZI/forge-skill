Forge は **ローカルファーストの Claude Code パーソナエンジン**です。  
やることはふたつ：

- **forge-self**：あなた自身の話し方・意思決定のパターン・盲点を蒸留し、自分をより明確に見るためのデジタル分身を生成する。
- **forge-persona**：チャット履歴・記憶・描写から、誰かの話し方・習慣・インタラクションのクセを蒸留し、その人の"声の温度"を近似保存する。

すべてのデータはローカルで処理されます。サーバー不要。

> ⚠️ 本プロジェクトは個人の記憶と感情的な癒しのみを目的としています。嫌がらせ・ストーキング・プライバシー侵害への利用は厳禁です。

## なぜ Forge を作ったのか

> 「師匠、まだこのやり方が身につかないんです。」  
> 「ね、一生そばにいるから。」  
> 「お母さん、もう一人でやれるよ。」

言いきれなかった言葉がある。  
もういない人がいる。

土の塊に感情は湧かないし、光る画面にも湧かない。  
でも、その画面の向こうに、かつて愛した人・頼った人・今も恋しい人がいるかもしれない。

Forge は誰かを蘇らせようとしているわけでも、誰かの代わりになろうとしているわけでもない。  
ただ、チャット履歴・話し方の癖・やりとりの痕跡から、その"大体"を組み立てようとしている。  
せめて、あの人の話し口調を残しておくために。

もうひとつの孤独もある。自分が見えなくなること。

多くの場合、私たちが足りないのは"最良の答え"ではない。  
何が健康的か、何が長期的に正しいか、何を続けるべきかは、わかっている。  
でも、わかることと、できることは違う。

だから人が本当に必要としているのは、アドバイスではなく、  
自分を正直に映し出してくれる鏡だ。

Forge はその鏡です。  
人格を鍛えるツール。自分を蒸留し、身近な人も蒸留する。

## Forge でできること

### 1. forge-self — 自分を蒸留する

こんな素材から「人格のベース」を抽出します：

- ガイド付き対話
- 日記 / ノート
- チャット履歴
- SNSの投稿

そしてそれを以下に活かします：

- 自己内省
- 意思決定サポート
- 複数変体の分身会議
- 盲点の可視化とコスト分析

こんなシーンに向いています：

- 「何が正しいかはわかってる。でも決められない。」
- 「なぜ同じ種類の問題でいつも詰まるのか知りたい。」
- 「アドバイスはいらない。自分をもっとクリアに見たい。」

---

### 2. forge-persona — 他者を蒸留する

こんな素材から、その人の人格輪郭を抽出します：

- WeChatのチャット履歴
- テキスト書き出し
- SNSコンテンツ
- あなたの記憶や描写

そして近似的に再現します：

- 話し方のスタイル
- 口癖とトーン
- あなたとのやりとりの習慣
- 境界線と典型的な反応パターン

こんなシーンに向いています：

- 古い友人の話し口調を残したい
- 恩師・元上司のコミュニケーションスタイルを保存したい
- 去っていった人がどう返してくれたかを覚えておきたい
- エージェントに「この人らしさ」を持たせたい

---

### 3. use-self — 分身会議

Forge は「自分に似たAI」を持つだけのツールではありません。  
具体的な意思決定の場面で、パラメータの違う複数の自分を生成します：

- より慎重な自分
- より決断力のある自分
- 長期視点の自分
- 関係性を重視する自分

彼らはあなたの代わりに決めません。  
彼らがやるのは、これらを一緒に広げて見せることです：

- あなたが本当に気にしていること
- 各選択のコスト
- 見落としていた盲点
- 自分の中の矛盾

手に入るのは「最適解」ではなく、**明晰さ**です。

---

### 4. use-persona — その人の言い方で話しかける

蒸留済みの人格プロファイルを読み込むと、Forge は Claude に：

- その人のメッセージの長さで返させる
- その人の口癖で話させる
- その人のインタラクション習慣で反応させる
- その人の境界線や禁止エリアを保持させる

これは蘇生でも、代替でもない。  
記憶の痕跡から形成された、近似的な再現です。

根本的にやっていることは同じです：

## 仕組み

Forge は「人格の構築」と「人格の使用」を分けています。

### Step 1: Forge フェーズ
以下のシグナルを収集・抽出します：

- 対話
- チャット履歴
- 日記
- SNS投稿
- ユーザーの修正フィードバック

それを構造化された人格プロファイルに整理します。

### Step 2: Use フェーズ
そのプロファイルは2方向に活用できます：

- **use-self**：意思決定の鏡として
- **use-persona**：記憶駆動のロールプレイとして

### Step 3: ローカルファースト
すべての解析と人格生成はローカルで完結します。  
あなたのチャット履歴や記憶は、マシンの外に出る必要がありません。

## forge-self が意味を持つ理由

私たちに足りないのは、いつも「最良の答え」ではありません。

揚げ物が不健康なのはわかってる。でも食べたら美味しい。  
運動を続けた方がいいのはわかってる。でもサボると楽だ。  
長期的に正しいことの大切さはわかってる。でも毎回実践できるとは限らない。

だから forge-self はあなたの代わりに決めません。  
あなたの話し方・考え方・意思決定のパターンを抽出して、  
パラメータの違う複数の自分に変換し、第三者視点から自分を見直す手助けをします。

自己陶酔のためじゃない。  
局中にいても、鏡を持てるように。

---

## forge-persona が意味を持つ理由

ずっとそばにいる人なんていない。

友人は遠ざかり、同僚は去り、愛した人がいつかいなくなることもある。  
記憶は薄れていく。でも、あの人の話し口調・あなたへの返し方・ふたりだけの小さなやりとり——それがそんなに早く消えていいはずがない。

forge-persona は蘇生でも、代替でも、欺きでもない。  
ただ、その人が残した痕跡から、大体を組み立てようとするだけ。

せめて、あの人の話し口調を残しておくために。

## インストール

### グローバルインストール（全プロジェクトで使える）

```bash
git clone https://github.com/YIKUAIBANZI/forge-skill.git ~/.claude/skills/forge-skill
```

### プロジェクトレベルのインストール（Gitリポジトリのルートで実行）

```bash
mkdir -p .claude/skills
git clone https://github.com/YIKUAIBANZI/forge-skill.git .claude/skills/forge-skill
```

インストール後に Claude Code を再起動すれば、4つのスキルが自動ロードされます。追加設定は不要。

オプション：素材解析ツールのインストール（WeChat / SNS / 日記）

```bash
pip install -r ~/.claude/skills/forge-skill/requirements.txt
```
