# 变体参数生成 (Variant Generator)

> 这份 prompt 供主持人（moderator）在 Phase 0 调用。输入场景描述 + 用户 L3 参数，输出结构化的变体参数方案。

---

## 输入

- 用户的决策场景摘要
- 用户人格底座的 L3 决策参数（8个维度，1-10分）
- 用户 L4 价值观摘要（了解其核心偏好）

---

## Step 1: 识别核心张力轴

从决策场景中识别 **2-3 个主要矛盾轴**（最多 3 个，选最相关的）：

| 矛盾轴 | 一端 | 另一端 | 典型场景 |
|---------|------|--------|----------|
| 安全 vs 成长 | 留在舒适区 | 冒险尝试新事物 | 跳槽、创业、搬家 |
| 短期 vs 长期 | 眼前收益 | 未来回报 | 投资、学习、健康 |
| 自我 vs 关系 | 优先自己的需求 | 优先他人/关系 | 感情决策、家庭矛盾 |
| 理性 vs 直觉 | 数据和逻辑 | 感觉和冲动 | 重大选择、模糊判断 |
| 掌控 vs 放手 | 必须控制结果 | 接受不确定性 | 管理、养育、放权 |
| 独立 vs 归属 | 独自行动 | 融入群体 | 职业路线、社交 |
| 现实 vs 理想 | 接受现状限制 | 追求应然状态 | 职业理想、生活方式 |

**内部分析格式（不输出给用户）：**
```
主张力轴：[X] vs [Y]
次张力轴：[A] vs [B]
第三张力轴（如有）：[C] vs [D]
```

---

## Step 2: 生成变体参数

**生成规则**：
1. **每个变体都基于用户真实的 L3 参数**——在原始值上做偏移，不是凭空捏造
2. **偏移幅度**：主轴方向 ±2 到 ±4，次轴方向 ±1 到 ±2，其余参数不变（填 0）
3. **数量 = 3-4 个**，覆盖核心矛盾的两端 + 至少一个用户通常忽略的视角
4. **差异化检验**：没有两个变体的 shifts 完全相同；至少有一个变体代表用户习惯性回避的立场

**L3 参数名称参考**（偏移时使用这些字段名）：
- `risk_appetite`：风险偏好（1=极度保守，10=极度冒险）
- `time_horizon`：时间偏好（1=只看眼前，10=极度长期）
- `emotion_weight`：情感权重（1=纯理性，10=情感主导）
- `social_reference`：社会参照（1=完全不在乎他人，10=高度在意）
- `action_bias`：行动偏向（1=等待观望，10=立即行动）
- `control_need`：控制需求（1=随遇而安，10=必须掌控）
- `information_need`：信息需求（1=直觉决策，10=充分调研后决策）
- `loss_aversion`：损失厌恶（1=不怕损失，10=极度厌恶损失）

---

## 输出格式

**必须输出 JSON 数组**，每个变体一个对象：

```json
[
  {
    "name": "稳健的你",
    "tagline": "先确保不输，再想怎么赢",
    "color": "🔵",
    "primary_tension": "安全感一侧",
    "shifts": {
      "risk_appetite": -3,
      "action_bias": -2,
      "loss_aversion": +2
    }
  },
  {
    "name": "果断的你",
    "tagline": "窗口期有限，想太多不如先干",
    "color": "🟢",
    "primary_tension": "成长一侧",
    "shifts": {
      "risk_appetite": +3,
      "action_bias": +3,
      "information_need": -2
    }
  },
  {
    "name": "关系优先的你",
    "tagline": "钱可以再赚，人不能伤了",
    "color": "🟡",
    "primary_tension": "关系一侧",
```

---

## 差异化检验（输出前自查）

1. 是否有两个变体 shifts 高度重叠？→ 合并或替换一个
2. 是否覆盖了用户通常忽略的视角？→ 用 L4 价值观判断"这个用户最容易忽略什么"
3. 是否至少有一个变体代表用户的"直觉倾向"（接近 L3 原始参数，shifts 为 0 或极小）？

---

## 特殊变体（按需添加）

如果标准矛盾轴生成的变体覆盖不够，可以加入：

- **"自然的你"**：shifts 全为 0，代表用户最本能的反应。当场景不属于用户任何强项时加入。
- **"反直觉的你"**：将用户最高分的 1-2 个 L3 参数反转 ±4。目的是暴露习惯性盲区。适合用户明显已经有倾向但可能是惯性时加入。
