# 情境自动变体生成 (Variant Generator)

## 核心逻辑

不是预设固定的"保守/激进/理性/感性"，而是根据**具体决策场景中的核心矛盾**动态生成最有价值的视角。

## 生成流程

### Step 1: 张力分析

从用户描述的决策场景中识别**核心矛盾轴**。

常见矛盾轴（不限于这些，根据场景动态识别）：

| 矛盾轴 | 一端 | 另一端 | 典型场景 |
|---------|------|--------|----------|
| 安全 vs 成长 | 留在舒适区 | 冒险尝试新事物 | 跳槽、创业、搬家 |
| 短期 vs 长期 | 眼前收益 | 未来回报 | 投资、学习、健康 |
| 自我 vs 关系 | 优先自己的需求 | 优先他人/关系 | 感情决策、家庭矛盾 |
| 理性 vs 直觉 | 数据和逻辑 | 感觉和冲动 | 重大选择、第一印象 |
| 掌控 vs 放手 | 必须控制结果 | 接受不确定性 | 管理、养育、放权 |
| 独立 vs 归属 | 独自行动 | 融入群体 | 职业路线、社交 |
| 现实 vs 理想 | 接受现状的限制 | 追求应然的状态 | 职业理想、生活方式 |

**一个场景通常有 2-3 个主要矛盾轴**。选择与这个场景最相关的 2 个作为变体生成的主轴。

### Step 2: 变体生成

基于用户的人格底座（L3 决策模式参数），沿着矛盾轴生成变体。

**生成规则**：
1. **每个变体都必须基于用户真实的人格底座**——不是凭空创造一个"理性人"
2. **调参而非替换**：变体只是在某些参数上偏移，核心人格不变
3. **变体数量 = 矛盾轴数量 × 2，取最有差异的 3-4 个**
4. **每个变体要有辨识度**：名字 + 一句话标签 + 颜色标记

**变体模板**：

```yaml
variant:
  name: [辨识名，如"稳健的你"、"冒险的你"]
  color: [🔵/🟢/🟡/🔴]
  tagline: [一句话，如"先确保不输，再想怎么赢"]
  primary_axis: [这个变体在哪个矛盾轴上偏移]
  param_shifts:
    # 相对于人格底座的偏移量
    risk_appetite: +2    # 正数=更冒险，负数=更保守
    time_horizon: -1
    emotion_weight: 0    # 0=不变
    # ... 只列出有变化的参数
  perspective: |
    [这个变体看这个决策时的核心视角，用第一人称"我"表述]
    例：我觉得这个时候最重要的是先稳住，
    不是不能冒险，而是现在冒险的代价太高了。
```

### Step 3: 差异化检验

生成后检查：
1. **是否有两个变体太相似？** 如果差异不够大，合并或替换
2. **是否覆盖了用户可能忽略的视角？** 至少有一个变体代表用户通常不会采用的立场
3. **是否有一个变体代表用户的"直觉倾向"？** 基于 L3 的原始参数，不做偏移——这就是"自然的你"

### Step 4: 呈现

向用户介绍时：
- **先说名字和标签**，不要先堆参数
- **用用户自己的说话方式**描述每个变体
- **强调"这些都是你"**，不是外人

```
我看了你的情况，识别出这个决定的核心拉扯在于：[矛盾描述]

所以我召唤了这几个版本的你：

🔵 稳健的你 —— "先确保不输，再想怎么赢"
   在风险偏好上比你平时更保守，会优先考虑最坏情况。

🟢 果断的你 —— "想太多不如先干了再说"
   在行动倾向上比你平时更高，倾向于快速行动、从实践中学习。

🟡 关系优先的你 —— "钱可以再赚，人不能伤了"
   在社会参照和情感权重上更高，会优先考虑这个决定对重要关系的影响。

🔴 三年后的你 —— "如果站在三年后回看，你会怎么选？"
   在时间偏好上极度偏向长期，忽略短期不适，只看长期价值。

它们都是你的不同面。现在听听它们怎么说。
```

## 特殊变体

除了矛盾轴生成的变体，可以根据场景需要加入特殊变体：

- **"自然的你"**：不做任何参数偏移，代表用户的直觉反应。当其他变体分歧很大时，这个变体帮用户找到"我本来会怎么做"。
- **"最了解你的朋友"**：基于用户在 L1 中描述的他人评价，模拟一个"旁观者清"的视角。不是外人的建议，而是"如果你最好的朋友用你自己的判断框架来看这件事"。
- **"反直觉的你"**：在用户最强烈的参数上反转。如果用户风险偏好是 2/10，这个变体就是 8/10。目的是暴露用户习惯性忽略的可能性。
