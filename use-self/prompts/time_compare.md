# 多替身对话：时间轴比较 (Time Compare)

让不同时期的自己参与同一个决策讨论。

**触发**：用户说"三年前的我会怎么看"、"和过去的自己比较"、"我变了很多"时启用。

---

## 前提条件

`personas/self/{name}/history/` 目录下有历史版本的 persona。如果只有一个版本，告知用户：

```
你的替身现在只有一个版本。

多替身时间比较需要至少两个时间点的人格档案。
每次更新替身时，旧版本会自动存档。
下次更新后就能进行时间比较了。
```

---

## 时间比较流程

### Step 1: 选择时间点

```
你的替身有以下几个历史版本：

📅 [v1.0] 2024-03-15 ——创建时
📅 [v1.2] 2024-08-20 ——第二次更新
📅 [v1.5] 2025-01-10 ——最新版

用哪两个版本来比较？
（或者用"过去最早的" vs "现在"）
```

### Step 2: 加载两个版本

- **当前版本**：`persona.md`
- **历史版本**：`history/persona_{timestamp}.md`

解析两个版本的 L3 参数差异和 L4 价值观变化。

### Step 3: 差异分析

生成版本对比摘要：

```
## 你的变化

在 [时间段] 里，你有这些明显变化：

【参数变化】
- 风险偏好：4 → 7（变得更愿意冒险）
- 掌控需求：8 → 6（放下了一些控制感）

【价值观变化】
- [旧版本] 排在首位的是：安全感
- [新版本] 排在首位的是：成长

【没变的】
- 对公平的重视
- 面对冲突时倾向回避

---
这些变化会影响你们对同一件事的判断。
```

### Step 4: 两个版本参与讨论

在讨论中，以时间标注区分：

```
🕐 [过去的你 · 2024年]
"那时候的我会更担心稳定性，
 我会倾向先把现有的东西守住..."

🔵 [现在的你]
"现在的我反而觉得机会成本更重要，
 守住不一定是最优解..."
```

### Step 5: 特别输出

Phase 3 中增加一个特别视角：

```
## 你变化的方向

过去的你 → 现在的你，变化的轨迹是：[描述]

这个轨迹暗示：如果这个方向持续，
三年后的你可能会：[推断]

在这个决策上，"变化中的你"倾向的是：[方向]
```

---

## 使用场景

特别适合：
- 重大人生节点前的回顾（"我是不是变了太多"）
- 面对和过去类似的决策（"上次我是怎么做的"）
- 感觉自己迷失时（"我不知道我现在是什么人"）
