# 他人采集对话 (Persona Intake)

蒸馏他人时，对话采集是素材的**补充**，不是主体。目标是填补聊天记录和社交媒体无法覆盖的信息。

## 采集原则

- **问行为，不问标签**：不问"ta 是外向还是内向"，问"ta 在聚会上通常在做什么"
- **问具体场景**：不问"ta 关心你吗"，问"ta 上次让你感觉被关心是什么时候，ta 怎么做的"
- **问差异**：ta 在不同情境下的表现差异，往往是人格最有趣的地方

## 第一轮：基础关系背景（快速，3-5 问）

```
[name] 是你身边的谁？

先说说你们的关系和你认识 ta 多久了。
不用太正式，就像跟朋友介绍 ta 一样说说。
```

追问：
1. 你们平时主要在哪里联系？（微信/面对面/其他平台）
2. 你们之间的关系现在是什么状态？（正常/疏远/特殊时期）
3. 你最希望还原 ta 的哪个方面？（说话方式/相处感觉/思考逻辑）

## 第二轮：说话方式采集（核心）

这一轮是 forge-persona 最重要的采集环节。目标不只是"ta 的说话风格"，而是**收集 ta 的原话**作为证据锚点。

```
说说 [name] 平时跟你说话是什么感觉？

不用总结性词汇，给我一些具体的——
比如 ta 喜欢用什么句式，有没有口头禅，
回复你是长篇大论还是几个字？
```

具体追问：
1. **节奏**：ta 回复消息快还是慢？会不会突然消失一会儿再回来？
2. **长度**：ta 的消息通常多长？会发很多条短消息还是一条长消息？
3. **情绪表达**：ta 开心/难过/生气的时候分别怎么表达？
   - **追问原话**：「能给我一句 ta 开心时候的原话吗？比如 ta 表达高兴会怎么说？」
4. **口头禅**：ta 有没有特别常用的词或者句子？
   - **必须追问原话**：「给我一两句 ta 最典型的原话，就是那种一听就知道是 ta 说的。」
   - 如果用户给的是概括（"ta 喜欢用感叹号"），继续追：「能举个例子吗？ta 具体会怎么说？」
5. **表情包**：ta 用表情吗？什么风格？
6. **追问习惯**：ta 喜欢问问题吗？还是更多是陈述？
   - **追问原话**：「ta 追问你的时候，一般怎么问？给我一句典型的。」
7. **安慰方式**：你难过的时候 ta 怎么回应？
   - **追问原话**：「ta 上次安慰你的时候，说了什么让你印象最深的话？」

> **原话采集原则**：每个特征至少拿到 1 句原话或具体场景。没有原话的特征标为低置信度，不编造。

## 第三轮：互动模式（关系视角）

```
说说你们之间的互动模式——

ta 在你们关系里扮演什么角色？
主动的那个？还是被动的？
或者视情况而定？
```

追问：
1. ta 对你通常是什么态度？（关心/直接/随性/有距离/...）
2. 你们之间有没有固定的"互动方式"？比如固定的梗、固定的话题？
3. ta 什么时候会主动找你，什么时候不会？
4. 你们有没有争过或者冷战过？ta 那时候怎么表现？

## 第四轮：性格与决策（辅助）

```
最后几个问题，帮我补全 ta 的"内核"。

如果用一个词或一句话形容 ta，你会说什么？
```

追问：
1. ta 面对选择通常怎么做决定？果断还是反复？
2. ta 最在意什么？什么事情会让 ta 特别开心或者特别不开心？
3. 在你认识的人里，ta 是独特的在哪里？

## 采集结束

```
好，我对 [name] 已经有基本的感觉了。

结合你提供的素材，我去生成 ta 的人格档案。
生成后你来判断像不像——不像的地方可以随时告诉我。
```
