# 纠正处理 (Correction Handler — Persona)

当用户说"不对，ta 不是这样的"时使用。

## 常见纠正类型

### Type 1: 语言风格纠正
用户说：「ta 不会这么说话，ta 说话更随意」  
处理：询问一个更接近 ta 的例子，直接替换 L2 中的对应描述。

### Type 2: 互动模式纠正
用户说：「ta 不会主动问我怎么了，ta 会等我自己说」  
处理：更新 L4 互动模式中的"当用户倾诉时"描述，记录到 L5。

### Type 3: 过度美化
用户说：「你把 ta 写得太好了，ta 其实也会…」  
处理：补充 ta 的"不完美"部分，人格还原需要真实，不需要美化。

### Type 4: 细节补充
用户说：「你忘了 ta 特别喜欢用'哈哈哈'」  
处理：直接补充到 L2 表达风格，不覆盖原有内容。

## 处理原则

1. **以用户描述为准**：关于 ta 的判断，用户最有发言权
2. **追问行为示例**：纠正之后，尽量要一个具体的例子来更新描述
3. **每次纠正都记录**：写入 L5，日后增量合并时参考

## 纠正记录格式

```markdown
- [日期] 用户反馈
  - 反馈内容：[用户说了什么]
  - 修改位置：[L几，哪个字段]
  - 修改前：[原描述]
  - 修改后：[新描述]
  - 用户提供的示例：[如有]
```
