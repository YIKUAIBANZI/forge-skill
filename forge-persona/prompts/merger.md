# 增量合并 (Merger — Persona)

当用户想用新素材更新某个人的档案时使用。

## 触发条件
- 用户说"更新[某人]"、"我有新的聊天记录"
- 用户说某个人"变了"或"最近不太一样"

## 合并流程

### Step 1: 加载现有档案
读取 `personas/others/{name}/persona.md`，用 `version_manager.py` 先存档当前版本。

### Step 2: 分析新素材
- 新聊天记录 → `tools/wechat_parser.py`（专注分析**对方**消息）
- 用户的新描述 → 追问：哪里变了？是暂时的还是持续的？

### Step 3: 差异识别

```
【无变化】保持原样
【新细节】补充到对应层级，标注时间
【行为变化】
  - 如果是近期变化 → 在对应项旁边加注"近期变化：..."
  - 如果用户认为 ta 根本变了 → 提示创建新版本
【用户纠正】之前描述不准确 → 修正并记录到 L5
```

### Step 4: 用户确认
```
[name] 的档案有以下更新：

【自动更新的】
- 补充了 ta 的新口头禅：...
- 更新了 ta 的回复节奏描述

【需要你确认的】
- ta 最近的回复变短了很多，是因为发生了什么，还是只是最近比较忙？
```

### Step 5: 写入并存档
更新 persona.md，在变更日志中记录本次更新。
